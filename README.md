# ✨ EssentialSkript

> 🔥 *May this spark propel the development of Minecraft servers!*  
> 🔥 *愿这份薪火，推进MC服务器的发展！*

📖 A curated collection of handy Skript scripts. Empowering your Minecraft server with simple code and boundless possibilities.

## 📖 About This Project
**EssentialSkript** is an open-source repository dedicated to sharing practical, elegant, and easy-to-use Skript scripts. Whether you are a server owner looking for out-of-the-box features or a developer seeking inspiration, we hope this collection brings value to your server.

🤝 We believe in the spirit of open source. Feel free to explore, use, and contribute!

## 🚀 Available Scripts

| Script Name | Description | MC Version |
| :--- | :--- | :--- |
| 🎆 `WelcomeSystem` | Custom join messages with philosophical quotes & firework sounds. | 1.16+ |
| ⏳ *More coming soon...* | *Stay tuned for more essential scripts!* | *-* |

## 📦 How to Install
1. ⚙️ Ensure you have the **Skript** plugin installed on your server.
2. 📥 Download the `.sk` file from the `scripts/` folder.
3. 📂 Place the file into your server's `plugins/Skript/scripts/` directory.
4. 🎮 Type `/sk reload <script_name>` in-game or restart your server.

## 🤝 Contributing
We highly encourage contributions! If you have written a useful Skript or want to improve an existing one:
1. 🍴 Fork this repository.
2. 🌿 Create your feature branch (`git checkout -b feature/AmazingScript`).
3. 💬 Commit your changes (`git commit -m 'Add some amazing script'`).
4. 📤 Push to the branch (`git push origin feature/AmazingScript`).
5. 🎯 Open a Pull Request.
